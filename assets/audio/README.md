# Music slot

Drop a looping background track here as `music.mp3` and the demo picks it up
automatically (src/audio.js fetches it after the first user gesture; a 404 is
silently ignored, so shipping without music is fine).

Licensing: the **recording** must be public domain or CC0 — a public-domain
*composition* is not enough, since the performance/recording carries its own
copyright. Musopen (musopen.org) hosts PD/CC0 recordings of classical works.
Keep it quiet and unobtrusive; default in-app music gain is 0.12.
